# AudioWave Design System

Source: Stitch project `projects/14843272429057423142`.

## Foundation

- Platform: mobile-first wellness web app.
- Theme: premium dark mode with calm audio, breathing, sleep, focus, and habit tracking.
- Primary color: electric aqua `#13daec`, used for active states, primary actions, waveform progress, and positive completion.
- Typeface: Manrope.
- Shape: rounded but controlled. Use 12px for feature cards, 10px for compact cards, full radius only for pills and circular controls.
- Atmosphere: quiet, immersive, polished, app-like, high contrast, sensory but not decorative.

## UI Rules

- First screen must be the usable app dashboard, not a marketing landing page.
- Mobile nav is persistent at the bottom with five destinations: Home, Library, Player, Routine, Progress.
- Use icon-first controls with accessible labels.
- Keep text compact and scannable. Avoid instruction copy inside the app.
- Use real visual media for audio sessions; never rely on abstract gradients alone.
- Cards should represent actual content or tools. Avoid cards inside cards.
- Preserve dense, operational spacing for repeat use on mobile.

## Components

- Dashboard hero: currently recommended session, action, session art, and quick stats.
- Library: search, segmented category filters, featured collection, session list.
- Player: full-bleed visual atmosphere, waveform, timeline, transport controls, volume.
- Routine: week selector, scheduled sessions, on/off toggles, addable suggestions.
- Progress: completion ring, weekly metrics, insight cards.
