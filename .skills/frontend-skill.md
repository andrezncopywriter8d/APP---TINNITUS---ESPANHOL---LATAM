# Frontend Design Skill

Use this whenever editing UI, layout, components, CSS or visual design.

## Visual Direction

This app is not a generic meditation app. It is a premium neuro-auditory protocol for tinnitus support called Onda Tesla.

## Design Goals

- Premium mobile-first neurotech interface.
- Calm dark mineral surfaces.
- Electric cyan as the only accent.
- Large readable touch targets for users 50+.
- Product UI, not marketing landing page.
- Focus on daily action, status and progress.

## Hard Rules

- Do not create generic dashboard-card mosaics.
- Do not use wellness/meditation copy like "Mindful Reset".
- Replace generic language with tinnitus/protocol language.
- Cards only when they contain interaction or important state.
- One main purpose per tab.
- One dominant action above the fold.
- Use utility copy, not advertising copy.
- Keep the bottom nav minimal.
- Use subtle motion only for hierarchy: player activation, progress ring, check-in modal.

Every UI change must preserve this product direction.

## Workflow

Always work in this order:

1. Analyze before editing.
2. Make a short plan.
3. Edit one area at a time.
4. Run the build.
5. Validate mobile visually.
6. Refine before concluding.
